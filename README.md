# Python 10 · Trường Đinh Thiện Lý

Khóa học: https://vuongndlst.github.io/python-10/

9 bài Python tương tác với môi trường chạy mã, nhiệm vụ, video bổ trợ và chế độ Tự học / học bù. Đăng ký bằng mã học sinh 7 chữ số. Tài khoản và hồ sơ dùng chung với SQL 11; tiến độ riêng từng khóa. Không yêu cầu xác nhận email.

Đây là bản xuất bản công khai. Học liệu riêng được tải sau xác thực và quyền tham gia khóa từ Supabase; thư mục này không chứa token quản trị, đáp án hay nguồn soạn riêng. Runtime Supabase JS sử dụng giấy phép MIT, lưu trong engine/supabase-LICENSE. Video nhúng dẫn tới nguồn freeCodeCamp.org và tài liệu tham khảo W3Schools; quyền thuộc các tác giả.

Giáo viên quản lí học sinh và hỗ trợ mật khẩu trong web. Lớp tự đặt tên, mã tham gia và giao bài theo lịch chưa được triển khai.
